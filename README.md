### 🛒 E-Commerce Website

- **Description:** A modern, full-stack e-commerce platform built with the MERN stack and designed around real-world shopping workflows. The platform provides a complete online shopping experience—from product discovery and cart management to secure checkout and order processing. It includes secure authentication, role-based access control, product and category management, wishlist and cart functionality, an admin dashboard, and integrated online payments through eSewa.

- **Tech Stack:** MongoDB • Express.js • React • Node.js • Tailwind CSS • REST API • eSewa Payment Gateway

- **Key Features:**
  - 🔐 Secure user authentication and authorization
  - 👥 Role-based access control for Users, Admins, and Super Admins
  - 🛍️ Product browsing, categories, search, and filtering
  - 🛒 Shopping cart and wishlist functionality
  - 📦 Checkout and complete order management
  - 💳 eSewa online payment integration
  - 🧑‍💼 Admin dashboard for managing products, categories, users, and orders
  - 📊 Product inventory and order status management
  - 📱 Responsive and modern user interface
  - 🔒 Secure backend architecture with protected API routes
  - 🗄️ MongoDB database with scalable data models
  - ⚡ RESTful API architecture for frontend-backend communication

- **Project Goal:** Built as a real-world full-stack application to demonstrate practical skills in frontend development, backend API design, database management, authentication, authorization, payment integration, and e-commerce workflows.

- **Repository:** https://github.com/sewak07/E-Commerce-Project
